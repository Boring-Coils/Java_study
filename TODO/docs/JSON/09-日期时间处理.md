# 09 日期时间处理

Jackson 对时间的序列化/反序列化一直是高频需求，尤其涉及 **Java 8+ 的 `java.time`**（`LocalDate`、`LocalDateTime`、`Instant`、`OffsetDateTime`、`ZonedDateTime` 等）。

## 1. 关键：注册 JavaTimeModule（JSR-310）

Jackson **2.x** 本体并不默认支持 `java.time`（`LocalDate` 等），必须引入模块并注册：

```xml
<dependency>
    <groupId>com.fasterxml.jackson.datatype</groupId>
    <artifactId>jackson-datatype-jsr310</artifactId>
    <version>2.17.2</version>
</dependency>
```

```java
ObjectMapper mapper = new ObjectMapper();
mapper.registerModule(new JavaTimeModule());
// 等价于：
// mapper.findAndRegisterModules();
```

> 在 Jackson **3.x** 中 `jsr310` 已内置到 `jackson-databind`，无需单独引入。本项目是 2.17.2，需要手动引入该依赖。
> 类位于 `com.fasterxml.jackson.datatype.jsr310.JavaTimeModule`。

## 2. 默认行为

注册 `JavaTimeModule` 后，默认：

- `LocalDate` → `"2026-09-29"`
- `LocalDateTime` → `"2026-09-29T10:15:30"`
- `Instant` → 可能写成数组 `[year,month,day,hour,minute,second,...]` 或字符串（受 `WRITE_DATES_AS_TIMESTAMPS` 影响，默认 true 时会包含纳秒数组）

关闭时间戳（推荐，输出 ISO 字符串）：

```java
mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);
```

```java
ObjectMapper mapper = new ObjectMapper();
mapper.registerModule(new JavaTimeModule());
mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);

LocalDateTime now = LocalDateTime.now();
String json = mapper.writeValueAsString(now);
// "2026-09-29T10:15:30.123"
```

## 3. 使用 @JsonFormat 自定义格式

`@JsonFormat` 可精确控制单个字段的日期输出格式（同时也影响反序列化解析）。

```java
import com.fasterxml.jackson.annotation.JsonFormat;

public class Event {
    public String name;

    @JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
    public LocalDateTime createTime;

    @JsonFormat(pattern = "yyyy-MM-dd")
    public LocalDate birthDate;
}

// 序列化 createTime -> "2026-09-29 10:15:30"
```

反序列化同样按该 pattern 解析：

```java
Event e = mapper.readValue("{\"name\":\"x\",\"createTime\":\"2026-09-29 10:15:30\"}", Event.class);
```

> `timezone` 只对带时区/时间戳的类型有影响；`LocalDate`/`LocalDateTime` 无时区，格式串按字面输出。

### shape 指定形态

```java
@JsonFormat(shape = JsonFormat.Shape.STRING, pattern = "yyyy/MM/dd")
public LocalDate d;
```

## 4. 全局日期格式设置

对 `java.util.Date` 类生效（`java.time` 仍主要靠模块+注解）：

```java
mapper.setDateFormat(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"));
mapper.setTimeZone(TimeZone.getTimeZone("GMT+8"));
```

## 5. 在线/格式对照表

| Java 类型 | 注册模块 | 默认输出（关闭 timestamp） | 常见 @JsonFormat pattern |
| --- | --- | --- | --- |
| `LocalDate` | JavaTimeModule | `2026-09-29` | `yyyy-MM-dd` |
| `LocalDateTime` | JavaTimeModule | `2026-09-29T10:15:30` | `yyyy-MM-dd HH:mm:ss` |
| `LocalTime` | JavaTimeModule | `10:15:30` | `HH:mm:ss` |
| `Instant` | JavaTimeModule | `2026-09-29T10:15:30Z` | `yyyy-MM-dd'T'HH:mm:ssX` |
| `OffsetDateTime` | JavaTimeModule | `2026-09-29T10:15:30+08:00` | `yyyy-MM-dd'T'HH:mm:ssXXX` |
| `ZonedDateTime` | JavaTimeModule | `2026-09-29T10:15:30+08:00[Asia/Shanghai]` | `yyyy-MM-dd'T'HH:mm:ssXXX` |
| `Date` / `Calendar` | databind 内置 | 时间戳数字 | 与 format 设置相关 |

> 关闭 `WRITE_DATES_AS_TIMESTAMPS` 后，`Instant` 通常会写成带 `Z`（UTC）的 ISO 字符串。

## 6. 反序列化时间字符串 → LocalDateTime

```java
String json = "\"2026-09-29T10:15:30\"";
LocalDateTime dt = mapper.readValue(json, LocalDateTime.class);

// 自定义格式字符串
String json2 = "\"2026/09/29 10:15:30\"";
// 需配合目标字段的 @JsonFormat 或使用 ObjectReader 自定义
ObjectReader r = mapper.readerFor(LocalDateTime.class)
        .with(JsonFormat.forPattern("yyyy/MM/dd HH:mm:ss"));
LocalDateTime dt2 = r.readValue(json2);
```

## 7. 时区与时戳数字

若保持默认 `WRITE_DATES_AS_TIMESTAMPS=true`，`java.util.Date` 会输出为**epoch 毫秒**数字：

```java
long ts = mapper.writeValueAsString(new Date()); // 类似 1664...
```

`Instant` 关闭 timestamp 前默认输出为**数值数组**（年/月/日/时/分/秒/纳秒）——这常是坑，建议始终关闭 timestamp。

## 8. 常见坑与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 报 `InvalidDefinitionException: Java 8 date/time type ... not supported by default` | 未注册 JavaTimeModule | `mapper.registerModule(new JavaTimeModule())` |
| LocalDateTime 变成数组 `[2026,9,29,10,15,30]` | `WRITE_DATES_AS_TIMESTAMPS=true` | `mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS)` |
| 时间少 8 小时 / 时区不对 | 默认时区 UTC | `@JsonFormat` 指定 `timezone`，或 `mapper.setTimeZone(...)` |
| 自定义格式反序列化失败 | 未告知解析格式 | 在字段 `@JsonFormat(pattern=...)` |

## 9. 完整示例

```java
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.SerializationFeature;
import com.fasterxml.jackson.datatype.jsr310.JavaTimeModule;
import java.time.LocalDate;
import java.time.LocalDateTime;

public class TimeDemo {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        mapper.registerModule(new JavaTimeModule());
        mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);

        Event e = new Event();
        e.name = "meeting";
        e.createTime = LocalDateTime.of(2026, 9, 29, 10, 15, 30);
        e.birthDate = LocalDate.of(1995, 5, 20);

        String json = mapper.writeValueAsString(e);
        System.out.println(json);
        // {"name":"meeting","createTime":"2026-09-29T10:15:30.000Z"...}
    }
}
```
