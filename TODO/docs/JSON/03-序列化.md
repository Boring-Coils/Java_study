# 03 序列化（Java 对象 → JSON）

序列化指把 Java 对象转换成 JSON。Jackson 默认读取对象的 **getter**（或公共字段）来决定输出哪些属性。核心类是 `ObjectMapper`（亦可使用只写的 `ObjectWriter`）。

## 常用方法

| 方法 | 返回 | 说明 |
| --- | --- | --- |
| `writeValue(File, Object)` | void | 写入文件 |
| `writeValue(OutputStream, Object)` | void | 写入字节流 |
| `writeValue(Writer, Object)` | void | 写入字符流 |
| `writeValueAsString(Object)` | String | 返回 JSON 字符串 |
| `writeValueAsBytes(Object)` | byte[] | 返回 JSON 字节数组 |

```java
ObjectMapper mapper = new ObjectMapper();

// 对象 -> 字符串
String json = mapper.writeValueAsString(new User("Alice", 30));
// {"name":"Alice","age":30}

// 对象 -> 文件
mapper.writeValue(new File("user.json"), user);

// 对象 -> 字节数组
byte[] bytes = mapper.writeValueAsBytes(user);
```

## 美化输出（Pretty Print）

```java
String pretty = mapper.writerWithDefaultPrettyPrinter().writeValueAsString(user);
/*
{
  "name" : "Alice",
  "age" : 30
}
*/
```

或开启全局特性：

```java
mapper.configure(SerializationFeature.INDENT_OUTPUT, true);
```

## 支持的类型

- **POJO**：通过 getter / 公共字段序列化。
- **Map / List**：Map 的 key、集合元素会递归序列化。
- **基本类型**：数字、字符串、布尔、null。
- **数组 / 集合**：`List`、`Set`、`Map`、数组。
- **Date / java.time**：默认按时间戳或 ISO 字符串（需配置）。
- **枚举（Enum）**：默认序列化为枚举名（`toString()`）。

```java
Map<String, Object> map = Map.of("name", "Bob", "age", 25);
String json = mapper.writeValueAsString(map); // {"name":"Bob","age":25}

List<Integer> list = List.of(1, 2, 3);
String json2 = mapper.writeValueAsString(list); // [1,2,3]
```

## 控制空值输出

Jackson 默认序列化 `null` 字段（输出 `"field":null`），可通过 `Inclusion` 过滤：

```java
mapper.setSerializationInclusion(JsonInclude.Include.NON_NULL);

User u = new User("Bob", null);
mapper.writeValueAsString(u); // {"name":"Bob"}，不再包含 age=null
```

## 循环引用处理

对象内部互相引用（如 A 持有 B，B 又持有 A）会导致死循环。

### 方式一：`@JsonIdentityInfo`

```java
@JsonIdentityInfo(generator = ObjectIdGenerators.PropertyGenerator.class, property = "id")
public class Dept {
    public int id;
    public List<Emp> emps;
}
```

### 方式二：`@JsonManagedReference` / `@JsonBackReference`（父子关系）

```java
public class Dept {
    @JsonManagedReference
    public List<Emp> emps;
}

public class Emp {
    @JsonBackReference
    public Dept dept;
}
```

### 方式三：写时序列化为 null

```java
mapper.configure(SerializationFeature.WRITE_SELF_REFERENCES_AS_NULL, true);
```

## 字段顺序

默认按声明顺序（Java 反射顺序不保证稳定），可通过注解或特性控制：

```java
// 字母序
mapper.configure(MapperFeature.SORT_PROPERTIES_ALPHABETICALLY, true);
```

或配合 `@JsonPropertyOrder`（见注解章节）。

## 根包装

将整个对象包一层（需配合 `@JsonRootName`）：

```java
@JsonRootName("user")
public class User { ... }

mapper.enable(SerializationFeature.WRAP_ROOT_VALUE);
String json = mapper.writeValueAsString(user);
// {"user":{"name":"Alice","age":30}}
```

## 通用写出示例（含 Map、枚举、日期）

```java
ObjectMapper mapper = new ObjectMapper();
mapper.registerModule(new JavaTimeModule());                 // 支持 java.time
mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS); // 输出 ISO 字符串

User u = new User("Alice", 30);
u.roles = List.of("ADMIN", "USER");
u.birthday = LocalDate.of(1995, 5, 20);

String json = mapper.writeValueAsString(u);
// {"name":"Alice","age":30,"roles":["ADMIN","USER"],"birthday":"1995-05-20"}
```

## ObjectWriter（只写、可复用、带配置）

需要反复执行**相同配置**的序列化时，可创建一次 `ObjectWriter` 复用：

```java
ObjectWriter writer = mapper.writerWithDefaultPrettyPrinter()
                            .with(SerializationFeature.INDENT_OUTPUT);
String a = writer.writeValueAsString(user1);
String b = writer.writeValueAsString(user2);
```

更多控制见 [05-注解](05-注解.md) 与 [02-ObjectMapper 与配置](02-ObjectMapper与配置.md)。

## 常见异常

| 异常 | 触发场景 |
| --- | --- |
| `InvalidDefinitionException` | 空 Bean（没有任何可序列化属性）且 `FAIL_ON_EMPTY_BEANS=true` |
| `JsonProcessingException` | 序列化过程中的各类处理错误（运行时为 `RuntimeException` 包装） |
| `JsonMappingException` | 映射问题，如循环引用处理失败 |
| `UnrecognizedPropertyException` | 反序列化遇到未知属性且 `FAIL_ON_UNKNOWN_PROPERTIES=true`（见反序列化） |
