# 01 概述与依赖

Jackson 是 FasterXML 维护的、Java 中最流行的 JSON 处理库，同时支持序列化（对象 → JSON）、反序列化（JSON → 对象），并提供三种互补的使用方式：

1. **Data Binding（数据绑定，最常用）** — 在 Java 对象和 JSON 之间双向转换，由 `ObjectMapper` 提供。
2. **Tree Model（树模型）** — 将 JSON 解析为一棵 `JsonNode` 树，动态读写，无需定义 POJO。
3. **Streaming API（流式 API，底层）** — 最小的读写前缀，`JsonParser` / `JsonGenerator`，逐 token 处理。

## 三大核心包

Jackson 整体由多个 artifact 组成，其中最核心的是 `jackson-core`（FasterXML 的顶层模块前缀）：

| artifactId | 作用 |
| --- | --- |
| `jackson-core` | 底层流式解析器与生成器（`JsonParser`、`JsonGenerator`、`JsonFactory`） |
| `jackson-annotations` | 标准注解（`@JsonProperty`、`@JsonIgnore` 等），独立于 core 存在 |
| `jackson-databind` | 数据绑定层，依赖上面两者，提供 `ObjectMapper`、`ObjectReader`、`ObjectWriter` 等 |

> `jackson-databind` 会**传递依赖** `jackson-core` 与 `jackson-annotations`，因此只需引入 databind 即可获得完整能力。

## Maven 依赖

### 1. 仅基础功能（当前项目已配置）

```xml
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.17.2</version>
</dependency>
```

### 2. 处理 Java 8+ 时间类型（LocalDate / LocalDateTime / Instant 等）

```xml
<dependency>
    <groupId>com.fasterxml.jackson.datatype</groupId>
    <artifactId>jackson-datatype-jsr310</artifactId>
    <version>2.17.2</version>
</dependency>
```

使用前注册模块（二选一）：

```java
ObjectMapper mapper = new ObjectMapper();
mapper.registerModule(new JavaTimeModule());
// 或
mapper.findAndRegisterModules();
```

### 3. 构造函数参数名自动绑定（配合 `-parameters` 编译参数）

```xml
<dependency>
    <groupId>com.fasterxml.jackson.module</groupId>
    <artifactId>jackson-module-parameter-names</artifactId>
    <version>2.17.2</version>
</dependency>
```

```java
mapper.registerModule(new ParameterNamesModule());
```

此模块依赖编译器保留参数名，需要在 `pom.xml` 中配置：

```xml
<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-compiler-plugin</artifactId>
    <version>3.13.0</version>
    <configuration>
        <release>21</release>
        <parameters>true</parameters>
    </configuration>
</plugin>
```

### 4. 其他常用模块

| 模块 | 用途 |
| --- | --- |
| `jackson-datatype-jdk8` | Java 8 数据类型（`Optional`、`OptionalInt` 等流式类型） |
| `jackson-module-kotlin` | Kotlin 支持（data class 等） |
| `jackson-module-jakarta-xmlbind-annotations` | 识别 Jakarta/JAXB 注解 |
| `jackson-dataformat-xml`、`jackson-dataformat-yaml`、`jackson-dataformat-csv` | 非 JSON 数据格式支持（同一套 API 处理 XML/YAML/CSV） |

## 版本说明

- Jackson 2 与 3 的 **group id 前缀不同**：2.x 为 `com.fasterxml.*`，3.x 为 `tools.jackson.*`。
- 本项目使用 **Jackson 2.17.2**，因此应使用 `com.fasterxml` 前缀。
- 在 Jackson **2.x** 中，`jsr310`、`jdk8`、`parameter-names` 都是独立模块需分别引入；这些模块在 **Jackson 3.x** 中被合并进 `jackson-databind`，无需再单独引入。
- `jackson-databind` 的 Major/Minor 版本必须与 `jackson-core`、`jackson-annotations` 保持一致，否则可能因序列化器 ID 不匹配而报错。

## 引入后的最小示例

```java
import com.fasterxml.jackson.databind.ObjectMapper;

public class HelloJackson {
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();

        // 序列化
        String json = mapper.writeValueAsString(new User("Alice", 30));
        System.out.println(json); // {"name":"Alice","age":30}

        // 反序列化
        User user = mapper.readValue(json, User.class);
        System.out.println(user); // User{name=Alice, age=30}
    }
}

class User {
    public String name;
    public int age;

    public User() {}                      // 反序列化需要（无参构造）
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

## 三个 API 的选用建议

| 场景 | 推荐 API |
| --- | --- |
| 对象与 JSON 互转、业务 POJO | **Data Binding**（ObjectMapper） |
| 结构不确定、动态字段、按路径取数 | **Tree Model**（JsonNode） |
| 超大文件、自定义 token 级处理、极致性能 | **Streaming API**（JsonParser/JsonGenerator） |

> Data Binding 与 Tree Model 底层都构建在 Streaming API 之上，通常无需直接使用流式 API。
