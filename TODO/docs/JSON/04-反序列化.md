# 04 反序列化（JSON → Java 对象）

反序列化指把 JSON 转换成 Java 对象。Jackson 默认通过 **setter**、公共字段或构造函数把 JSON 属性绑定到目标类。

## 常用方法

| 方法 | 说明 |
| --- | --- |
| `readValue(String, Class<T>)` | 从字符串读取 |
| `readValue(String, TypeReference<T>)` | 从字符串读取泛型类型 |
| `readValue(byte[], Class<T>)` | 从字节数组读取 |
| `readValue(File, Class<T>)` | 从文件读取 |
| `readValue(InputStream, Class<T>)` | 从流读取 |
| `readValue(Reader, Class<T>)` | 从字符流读取 |
| `readValue(JsonParser, Class<T>)` | 从解析器读取 |
| `readTree(String)` | 返回 `JsonNode` 树（见第 06 章） |

```java
ObjectMapper mapper = new ObjectMapper();
String json = "{\"name\":\"Alice\",\"age\":30}";

User user = mapper.readValue(json, User.class);
System.out.println(user.name); // Alice
```

## 反序列化对目标类的要求

- **有 `public class`** 且通常需要**无参构造**（Jackson 会通过 setter/字段注入）。
- 有 setter（用 setter 注入）或公共字段。
- 若只有带参构造，需注册 `ParameterNamesModule` 或使用 `@JsonCreator` / `@JsonProperty`（见下）。

### 无 setter 只有公共字段

```java
public class User {
    public String name;
    public int age;
}
```

### 只有 getter 没有 setter 的不可变类

需借助构造函数绑定，见 [10-Java Records 与不可变对象](10-JavaRecords与不可变对象.md)。

## 泛型类型（List / Map / 自定义泛型）

直接 `readValue(json, List.class)` 只能得到裸类型。要得到带泛型的 `List<User>`，必须用 `TypeReference`：

```java
import com.fasterxml.jackson.core.type.TypeReference;

String json = "[{\"name\":\"Alice\",\"age\":30},{\"name\":\"Bob\",\"age\":25}]";

List<User> users = mapper.readValue(json, new TypeReference<List<User>>() {});

Map<String, User> map = mapper.readValue("{\"a\":{...}}", new TypeReference<Map<String, User>>() {});
```

> `TypeReference` 的 `{}` 匿名子类在编译期保存泛型信息，这是 Jackson 将 JSON 绑定到具体泛型的关键。

## 处理未知字段：FAIL_ON_UNKNOWN_PROPERTIES

默认情况下，若 JSON 中某属性在目标类中不存在，反序列化会抛 `UnrecognizedPropertyException`：

```java
// 方式一：全局关闭
mapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);

// 方式二：类级别忽略
@JsonIgnoreProperties(ignoreUnknown = true)
public class User { ... }
```

推荐外部 API 场景用方式二（局部、精确），全局关闭容易掩盖拼写错误。

## 不完全必需的字段（JSON 缺少某属性）与默认值

- 目标类有**默认值**或字段有初始值时，Jackson 保留默认值。
- 目标类**未初始化且无匹配 JSON 属性**的引用类型字段为 `null`。
- 基本类型（`int` 等）若 JSON 缺少，会保留默认值（`0`）。

## 空字符串/单个值的处理

```java
// 让空字符串当作 null 对象
mapper.configure(DeserializationFeature.ACCEPT_EMPTY_STRING_AS_NULL_OBJECT, true);

// 允许单个值匹配单元素数组
mapper.configure(DeserializationFeature.ACCEPT_SINGLE_VALUE_AS_ARRAY, true);
List<Integer> nums = mapper.readValue("5", new TypeReference<List<Integer>>() {});
```

## 构造函数绑定

对于没有无参构造的类（不可变对象），用 `@JsonCreator` + `@JsonProperty`：

```java
public class User {
    private final String name;
    private final int age;

    @JsonCreator
    public User(@JsonProperty("name") String name,
                @JsonProperty("age") int age) {
        this.name = name;
        this.age = age;
    }
}
```

如果不想写 `@JsonProperty`，可注册 `ParameterNamesModule` 并开启 `-parameters`（详见 [01-概述与依赖](01-概述与依赖.md)）：

```java
mapper.registerModule(new ParameterNamesModule());
```

> 对 **Java Records**（`record`），Jackson 2.12+ 会自动绑定到规范构造函数，无需额外标注（见第 10 章）。

## 枚举反序列化

默认按枚举**名称**匹配；若要大小写不敏感，可开启特性或使用 `@JsonCreator`/`@JsonProperty`：

```java
// 方式一：全局（MapperFeature）
mapper.configure(MapperFeature.ACCEPT_CASE_INSENSITIVE_ENUMS, true);

// 方式二：注解
public enum Status {
    @JsonProperty("on") ON,
    @JsonProperty("off") OFF;
}
```

## 反序列化到 Map / Object / JsonNode

```java
// 到 Map
Map<String, Object> map = mapper.readValue(json, new TypeReference<Map<String, Object>>() {});

// 到通用对象（得到 LinkedHashMap 等）
Object obj = mapper.readValue(json, Object.class);

// 到 JsonNode 树
JsonNode node = mapper.readTree(json);
```

## 反序列化日期时间

```java
mapper.registerModule(new JavaTimeModule());
LocalDate date = mapper.readValue("\"1995-05-20\"", LocalDate.class);
LocalDateTime dt = mapper.readValue("\"2026-09-29T10:15:30\"", LocalDateTime.class);
```

详见 [09-日期时间处理](09-日期时间处理.md)。

## 读取 Input / 关闭资源

写入/读流时注意资源管理。`ObjectReader` 默认不会自动关闭传入的 `Closeable`，需要手动或在 `try-with-resources` 中关闭：

```java
try (InputStream is = new FileInputStream("user.json")) {
    User user = mapper.readValue(is, User.class);
}
```

## 常见异常

| 异常 | 触发场景 |
| --- | --- |
| `UnrecognizedPropertyException` | 未知属性且 `FAIL_ON_UNKNOWN_PROPERTIES=true` |
| `MismatchedInputException` | 类型不匹配，如期望 `int` 却给字符串 |
| `InvalidFormatException` | 数值/日期/枚举格式不合法 |
| `JsonMappingException` | 结构无法映射到目标类型 |
| `JsonProcessingException` / `JsonParseException` | JSON 语法错误或解析问题 |
| `ValueInstantiationException` | 无法实例化目标对象（如抽象类、无可用构造器） |
