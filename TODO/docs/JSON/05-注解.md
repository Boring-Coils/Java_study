# 05 注解

Jackson 的注解位于 **`com.fasterxml.jackson.annotation`** 包（由 `jackson-annotations` 提供）。按作用分为：命名与别名、忽略与包含、读写控制、多态、视图等。

## 命名与别名

### @JsonProperty

指定属性在 JSON 中的名称，同时影响序列化与反序列化。

```java
public class User {
    @JsonProperty("user_id")
    private String userId;

    private String name;
    // getter/setter...
}
// JSON: {"user_id":"123","name":"Alice"}
```

也常用于构造函数参数（配合 `@JsonCreator`）或仅用于指定必需属性（`required=true`）：

```java
@JsonProperty(required = true)
private int age;  // 反序列化时缺少会抛异常（受配置影响）
```

### @JsonAlias

反序列化时的**替代名称**（不影响序列化输出）。

```java
public class User {
    @JsonAlias({ "name", "userName" })
    private String name;
}
// 以下都能映射到 name：{"name":"A"}、{"userName":"A"}
```

### @JsonRootName

配合 `WRAP_ROOT_VALUE` 特性使用，指定根对象的名字。

```java
@JsonRootName("user")
public class User { ... }

mapper.enable(SerializationFeature.WRAP_ROOT_VALUE);
// 输出 {"user":{"name":"Alice"}}
```

### @JsonPropertyOrder

控制属性序列化顺序。

```java
@JsonPropertyOrder({ "age", "name" })
public class User { public int age; public String name; }
// 输出 {"age":... ,"name":...}
```

### @JsonRawValue

将属性值按**原生 JSON**输出（不进行转义）。

```java
public class Wrapper {
    @JsonRawValue
    public String json = "{\"a\":1}";
}
// 输出 {"json":{"a":1}}  而不是字符串
```

## 忽略与包含

### @JsonIgnore

序列化与反序列化都忽略该属性。

```java
public class Account {
    public String username;
    @JsonIgnore
    public String passwordHash; // 不会出现在 JSON 中
}
```

### @JsonIgnoreProperties(ignoreUnknown = true)

类级别忽略 JSON 中的未知属性（反序列化，容错）。

```java
@JsonIgnoreProperties(ignoreUnknown = true)
public class User { public String name; }
// JSON 中多余的 age 等字段会被忽略
```

### @JsonIgnoreType

忽略整个类型（用于类上，让该类型的所有实例都不参与 JSON）。

```java
@JsonIgnoreType
public class Secret { ... }
```

### @JsonInclude

控制属性的包含规则（等价于 `setSerializationInclusion`，但更局部）。

```java
import com.fasterxml.jackson.annotation.JsonInclude;
import static com.fasterxml.jackson.annotation.JsonInclude.Include.*;

public class User {
    @JsonInclude(NON_NULL)
    public String nickname;   // null 时不输出
    @JsonInclude(NON_EMPTY)
    public List<String> tags; // 空集合时不输出
}
```

### @JsonIgnoreProperties(allowGetters/ignoreGetters)

精确控制 getter 侧：

```java
@JsonIgnoreProperties(ignoreUnknown = true, ignoreGetters = { "password" })
public class User { ... }
```

## 读写（getter / setter）控制

### @JsonGetter / @JsonSetter

把特定的 getter / setter 绑定到指定的 JSON 属性名。

```java
public class User {
    private String fullName;

    @JsonGetter("name")
    public String getFullName() { return fullName; }

    @JsonSetter("name")
    public void setFullName(String name) { this.fullName = name; }
}
```

### @JsonSetter(nulls = ...) / @JsonProperty(nulls = ...)

控制 `null` 值的处理：

```java
@JsonSetter(nulls = Nulls.SKIP)          // JSON 中为 null 时不覆盖已有值
private String name;
// 或
@JsonProperty(nulls = Nulls.AS_EMPTY)
private String name;
```

### @JsonAnyGetter / @JsonAnySetter

处理动态、非预定义的附加字段（常配合 `Map`）。

```java
public class User {
    public String name;
    private Map<String, Object> extra = new HashMap<>();

    @JsonAnySetter
    public void setExtra(String key, Object value) { extra.put(key, value); }

    @JsonAnyGetter
    public Map<String, Object> getExtra() { return extra; }
}
// JSON: {"name":"A","hobby":"reader","level":5}  -> hobby/level 进入 extra 动态 Map
```

## 构造 / 创建

### @JsonCreator

标记反序列化时使用的工厂方法或构造函数。

```java
public class User {
    public final String name;

    @JsonCreator
    public User(@JsonProperty("name") String name) {
        this.name = name;
    }
}
```

可指定具体模式：

```java
@JsonCreator(mode = JsonCreator.Mode.PROPERTIES) // 按属性名绑定（推荐）
@JsonCreator(mode = JsonCreator.Mode.DELEGATING) // 把整个 JSON 交给单一参数
```

> 对于 Java `record`，Jackson 2.12+ 会自动使用规范构造函数，通常无需 `@JsonCreator`。

### @JsonFactoryMethodMarked（不常用）

一般使用 `@JsonCreator` 即可。

## 自定义序列化 / 反序列化器

### @JsonSerialize / @JsonDeserialize

指定自定义的序列化器 / 反序列化器、预写器。

```java
public class User {
    @JsonSerialize(using = CustomDateSerializer.class)
    @JsonDeserialize(using = CustomDateDeserializer.class)
    public Date birthday;
}
```

自定义类继承相应基类：

```java
public class CustomDateSerializer extends JsonSerializer<Date> {
    @Override public void serialize(Date value, JsonGenerator g, SerializerProvider p)
            throws IOException, JsonProcessingException {
        g.writeString(new SimpleDateFormat("yyyy-MM-dd").format(value));
    }
}
```

### @JsonView

视图过滤：不同 API 暴露不同字段集合。

```java
public class Views {
    public static class Public {}
    public static class Internal extends Public {}
}

public class User {
    @JsonView(Views.Public.class)
    public String name;

    @JsonView(Views.Internal.class)
    public String ssn;  // 仅 Internal 视图可见
}

// 使用
mapper.writerWithView(Views.Public.class).writeValueAsString(user);    // 只含 name
mapper.readerWithView(Views.Internal.class) ...                        // 反序列化对应视图
```

## 多态与类型信息

### @JsonTypeInfo + @JsonSubTypes

处理**继承体系**（父类引用，实际是子类对象）。

```java
@JsonTypeInfo(use = JsonTypeInfo.Id.NAME, property = "type")
@JsonSubTypes({
    @JsonSubTypes.Type(value = Dog.class, name = "dog"),
    @JsonSubTypes.Type(value = Cat.class, name = "cat")
})
public abstract class Animal { public String name; }
public class Dog extends Animal { public String bark = "wang"; }
public class Cat extends Animal { public String meow = "miao"; }

// 序列化 Dog 会输出 {"type":"dog","name":...,"bark":"wang"}
// 反序列化时根据 "type" 字段选择 Dog/Cat
```

### @JsonTypeName

配合 `JsonTypeInfo.Id.NAME` 指定类型名称（等效于 `@JsonSubTypes` 里的 name）。

```java
@JsonTypeName("dog")
public class Dog extends Animal { ... }
```

## 注解汇总表

| 注解 | 作用 | 影响序列化 | 影响反序列化 |
| --- | --- | --- | --- |
| `@JsonProperty` | 指定 JSON 属性名 | ✅ | ✅ |
| `@JsonAlias` | 反序列化别名 | ❌ | ✅ |
| `@JsonIgnore` | 忽略属性 | ✅ | ✅ |
| `@JsonIgnoreProperties` | 忽略一组属性/未知属性 | ✅ | ✅ |
| `@JsonIgnoreType` | 忽略整个类型 | ✅ | ✅ |
| `@JsonInclude` | 控制包含规则 | ✅ | ❌ |
| `@JsonGetter` / `@JsonSetter` | 绑定 getter/setter 到属性名 | ✅ | ✅ |
| `@JsonValue` | 用单方法输出对象表示 | ✅ | ✅（需 @JsonCreator 配合） |
| `@JsonCreator` | 标记创建方法 | ❌ | ✅ |
| `@JsonFormat` | 格式化（日期、数字、形态） | ✅ | ✅ |
| `@JsonPropertyOrder` | 属性顺序 | ✅ | ❌ |
| `@JsonRootName` | 根对象名 | ✅ | ✅ |
| `@JsonSerialize` / `@JsonDeserialize` | 自定义序列化器 | ✅ | ✅ |
| `@JsonView` | 视图过滤 | ✅ | ✅ |
| `@JsonTypeInfo` / `@JsonSubTypes` / `@JsonTypeName` | 多态 JSON | ✅ | ✅ |
| `@JsonAnyGetter` / `@JsonAnySetter` | 动态字段 | ✅ | ✅ |
| `@JsonManagedReference` / `@JsonBackReference` | 解决循环引用 | ✅ | ❌ |
| `@JsonIdentityInfo` | 循环引用按 ID 标识 | ✅ | ✅ |
| `@JsonRawValue` | 原生 JSON 输出 | ✅ | ❌ |
| `@JsonNullable`（第三方可选） | 可空包装 | — | — |

### 补充 @JsonValue

用单一方法表示整个对象：

```java
public class Money {
    public BigDecimal amount = new BigDecimal("10.5");
    @JsonValue
    public String toJson() { return amount.toString() + "CNY"; }
}
// 序列化输出 "10.5CNY" 而不是对象
```

## 组合注解 @Jacksonized / @JsonPOJOBuilder（Lombok 相关）

使用 Lombok + Jackson 时，加 `@Jacksonized` 可让 Builder 无需额外标注即可绑定到构造函数；或在自定义 builder 上使用 `@JsonPOJOBuilder`。

```java
@Builder
@Jacksonized      // Lombok + Jackson 友好
public class User { ... }
```

## 最佳实践

1. 外部分辨字段名差异优先用 `@JsonProperty`；容错别名用 `@JsonAlias`。
2. 防止敏感信息泄露用 `@JsonIgnore` 或 `@JsonInclude(NON_NULL)`。
3. 接口字段裁剪用 `@JsonView`；可复用性高、容易遗漏，慎用。
4. 继承多态优先用 `JsonTypeInfo.Id.NAME` + `@JsonSubTypes`。
5. 状态可用 `@JsonCreator` + 一个 `@JsonValue` 方法双向绑定枚举。
